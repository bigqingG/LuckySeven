# 资源压力与组合价值 V1

2026-11-07，按用户确认的最小范围接入。

| 项目 | 当前规则 |
|---|---|
| 直接补牌 | 2 张；回响后 3 张 |
| 换牌补牌 | 放回 2 张，抽 3 张；回响后抽 4 张 |
| 1 张凑数破防 | 下次攻击 +0 |
| 2 张凑数破防 | 下次攻击 +2 |
| 3 张及以上凑数破防 | 下次攻击 +4，封顶 |
| 破防攻击 | 攻击牌面 + 强攻 2（若有）+ 组合奖励，无视护甲 |
| 普通攻击 | max(1，攻击牌面 + 强攻 2（若有）− 护甲)，不享受组合奖励 |

破防本身不扣敌人生命。奖励在成功破防时按凑数牌张数锁定；选择、替换、收回攻击牌不会消耗奖励，确认一次攻击后清除。不能连续破防叠加；新回合、新战斗、重新开局均无残留奖励。两个幸运数字奖励相同。

保持原值：开局 5 张、手牌上限 9、27 张牌库、数字 1–9 各 3 张；玩家生命 30；敌人生命 18/24/30、护甲 3/4/5、反击 2/3/4；场间治疗最多 6；强攻 +2、守护格挡 3、回响下次补牌 +1。换出的牌仍在本次抽牌完成后放回牌库底；超限主动弃牌；凑数、换出和弃牌不触发附效。

## 界面与实现

- 保留复古像素冒险布局。中央公式显示组合奖励；确认破防后持续显示本次奖励。
- 单张普通攻击显示含护甲的预计伤害；破防攻击显示牌面、强攻、组合奖励及总伤害。未选攻击牌时提示选择，不把凑数总和误当作伤害。
- 预览和结算共用 `BattleSession.TryPreviewAttack`。预览不修改状态，正常攻击忽略组合奖励。
- 中文/英文提示、补牌按钮和玩法说明同步；复用现有字体及本地化表。没有新增场景对象、依赖包或复杂特效。
- 接入前备份：`Backups/BeforeResourceComboV1`。规则、UI、Web 的本轮验收见 `Docs/Validation/ResourceComboV1`。

## 试玩入口

构建目录：`Builds/WebGLV2`。运行 `Tools/Serve-Web.ps1` 后打开 `http://127.0.0.1:8078/`。需要 HTTP 服务，不能直接双击 index.html。

本轮验证侧重规则正确性、预览一致性、点击/拖拽与完整三场流程；不代表长期难度与策略平衡已经验证。试玩重点是低手牌时换牌是否值得，以及多花一张凑数牌换 +2 伤害是否有实际选择价值。
