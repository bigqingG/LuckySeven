日期：2026-11-07。已阅读 CardRulesV2.md、LocalizationAndPokerCards.md，并查看两张指定浏览器实机截图。以下为内置 image_gen 生成的概念效果图，不是 Unity 实机或可直接导入的完整 UI。未修改代码、场景、配置、玩法；只新增本目录的图片与说明。

## 统一比较基准

- 横屏 16:9 构图。工具原始输出均为 1672×941，比例近似 16:9；后续正式落地按 1920×1080 参考画布排版。
- 第 1/3 场、第 1 回合；命运掌牌人生命 30/30、格挡 0；残缺之骰生命 18/18、护甲 3、反击 2。
- 幸运数字 7 和 2；手牌 8/9、牌库 19、弃牌 0；中央尚未选牌。
- 从左到右固定：2♠守护、5♥强攻、9♦回响、1♥回响、3♠回响、5♠回响、4♣守护、7♠强攻。花色仅为视觉，不改变规则。
- 抽3张、换2抽4入口可见；此状态已补牌，所以置灰。无选择时攻击、破防、收回操作也置灰。
- 上方战斗信息与幸运数，中央出牌区与确认操作，底部叠放手牌；右上角语言入口。
- 本轮不展开悬停、破防动画或卡牌细节设计，待选择方向后深化。

## 1. 复古幸运牌桌

![复古幸运牌桌](01-retro-lucky-table.png)

配色：墨绿 #123D32、黄铜金 #B99752、米白 #F4EAD2。

布局思路：上方三组黄铜铭牌承载双方状态和幸运数；中央以毛毡缝线框明确落牌范围；底部米白纸牌突出数字和附效。圆形黄铜筹码强化幸运主题，木质外沿建立桌面感。

所需素材：毛毡与木边背景 1 张、残缺象牙骰敌人透明图 1 张、纸牌正反面共用框、黄铜面板与按钮九宫格、幸运数筹码底图、四花色与三附效图标、标题装饰。

成本估计：低至中。材质主要烘焙进静态贴图；金属高光不需要实时材质。注意减少重复金边装饰，优先保证数字阅读。

## 2. 神秘命运塔罗

![神秘命运塔罗](02-mystic-fate-tarot.png)

配色：深紫 #281B42、午夜蓝 #111C35、暗金 #AA8850；文字与卡面辅以羊皮纸色 #F0E5CF。

布局思路：星图线条串联上方信息；幸运数成为悬挂命运徽章；中央保留大块安静的深色区域；底部浅色塔罗牌与暗背景分离。敌人使用金裂纹石骰造型。

所需素材：星图背景 1 张、石骰敌人透明图 1 张、掌牌人头像 1 张（可选）、塔罗卡框与牌背、拱形/切角面板和按钮、星月装饰图集、幸运数吊坠底图、四花色与三附效图标。

成本估计：中。主要增加插画和装饰资源的制作工作量；烟雾可画在敌人贴图内，星图可静态化。无需真实体积雾。

## 3. 明亮卡通桌游

![明亮卡通桌游](03-bright-cartoon-boardgame.png)

配色：奶油白 #FFF5E4、湖蓝 #309CB6、珊瑚橙 #F27862；文字深墨色 #233F4A。

布局思路：大圆角状态贴纸配厚描边，中央用虚线明确可拖入区域；蓝橙幸运数筹码形成主视觉；手牌采用大数字和附效色签。骰子敌人的表情和创可贴强化轻松气质。

所需素材：简洁桌游背景 1 张、卡通骰子敌人透明图 1 张、圆角面板和按钮九宫格、通用卡框与牌背、两色筹码底图、四花色与三附效图标、少量星星/四叶草贴纸。

成本估计：低。平面形状、描边和固定阴影容易复用。推荐作为 Game Jam 工期优先的方向，后续表现可用少量位移、缩放和透明度变化。

## 4. 霓虹街机牌局

![霓虹街机牌局](04-neon-arcade-card-game.png)

配色：深黑 #090D17、青蓝 #25DCEB、玫红 #EF438F；文字冰白 #EDF9FF。

布局思路：上方使用切角仪表框，中央是清楚的发光出牌框，底部深色手牌以白色数字保持可读性。青蓝与玫红区分原有黑红花色，不新增规则；骰子敌人为街机机械轮廓。

所需素材：暗色网格背景 1 张、机械骰敌人透明图 1 张、切角面板与按钮九宫格、暗色卡框与牌背、预绘发光描边、幸运数徽章、四花色与三附效图标。

成本估计：低至中。发光烘焙到小贴图，搭配简单透明度变化即可；不以全屏 Bloom、实时灯光或大量粒子作为视觉前提。

## 共用落地原则

- 四套均可沿用现有 uGUI + TMP 和本地化结构，文字及牌面数字由真实文本组件呈现，不能将整张概念图直接当作可交互 UI。
- 中文/英文按钮与说明需留伸缩空间；概念图里的中文排版不等于英文布局已经验收。
- 共用卡框、花色和附效图标，不必制作 27 张完整卡图；底部最多 9 张手牌时再验证重叠与可点击范围。
- 保留已有悬停抬起、缩放和置顶行为；本轮展示普通手牌状态。
- 敌人先使用静态透明图片，面板和按钮复用九宫格切片；纹理大小、图集合并及真实浏览器表现需在方向确认后验证。
- 成本为基于素材与结构的相对设计估计，未开展 Web 性能测试。
- 本轮停在方向比较，等待用户选择后再深化卡牌、悬停状态和破防表现。
