# 幸运七 V2：卡牌战斗原型

本文件记录 2026-11-06 用户确认的新方案，覆盖原设计文档中的四则运算与旧伤害规则。原设计文档保留不改。

## 已实现规则

- 开局 5 张牌。牌库共 27 张，数字 1–9 各 3 张；卡牌具有稳定身份，抽牌、弃牌、洗牌不会复制卡牌。
- 每场战斗开始，从 1–10（排除 7）随机展示三个不同数字，由玩家选择一个作为本场第二幸运数字。7 始终有效。这里采用“每场战斗固定”，而非每回合重新选择。
- 每回合选择：抽 2 张；或选两张放回牌库底部，抽 3 张。放回的牌在本次抽牌之后归入牌库，避免立即抽回。（2026-11-07 资源与组合 V1 调整）
- 手牌保留到下一回合和下一场战斗。超过 9 张时，玩家先选择超出的牌弃掉；不会偷偷截断抽牌数量。
- 任意数量的选中卡牌，其**牌面数值之和**恰好等于 7 或第二幸运数字，就能破防。只有加法，没有运算符、整除或必须使用三张牌的限制。
- 凑数牌进入弃牌堆，本次破防不直接造成伤害。至少保留一张手牌，随后选一张攻击牌，点击 ATTACK；伤害为牌面数字加攻击附效加组合奖励，无视本次敌人护甲。
- 成功破防消耗 1 / 2 / 3 张及以上凑数牌时，组合奖励分别为 +0 / +2 / +4。两个幸运数字奖励相同；奖励仅供本次破防后的单次攻击，收回或更换攻击牌不丢失，不叠加、不跨回合或战斗保留。普通攻击不享受组合奖励。凑数牌附效仍不触发。
- 凑数时显示组合奖励；选定攻击牌后显示预计伤害和计算明细。预览不会扣血或消耗奖励，与确认攻击共用计算方法。伤害数字允许超过敌人剩余生命，实际生命最低为 0。
- 破防只创造一次攻击窗口；敌人生存后仍会反击，下回合护甲恢复。没有另加跳过反击的眩晕，以避免无限压制。
- 凑不出幸运数字时，可选一张牌进行普通攻击：减去敌人护甲，最低造成 1 点伤害。
- 三种卡牌附效仅在该牌用于攻击时触发：STRIKE（强攻）额外 2 伤害；WARD（守护）获得 3 格挡抵挡本次反击；ECHO（回响）下次补牌额外抽 1 张。用于凑数、换回或弃掉的牌不触发附效。
- 玩家生命 30；三名敌人生命 18/24/30、护甲 3/4/5、反击 2/3/4；场间回复最多 6 生命。格挡结算后清零，回响奖励可以带到下一场战斗。
- 牌库耗尽时将弃牌堆洗入牌库。赢下第三场后显示结算，可重新开局。

## 表现与范围

uGUI + TMP 的可点击卡牌、发牌滑入、鼠标悬停抬起、选中高亮、实时加法总和、破防与命中反馈、合成音效，以及抽牌堆/弃牌堆数量显示。当前 UI 仍为英文原型字库；未扩展商店、地图、长期成长或外部服务。

开发版 Web 提供只读的可见 HUD 状态镜像，供浏览器验收脚本核对点击结果；不暴露隐藏牌库顺序，不提供修改游戏状态的接口。录屏来自真实浏览器 Canvas 和游戏音频。

## 设计取舍

数值很简单，但一张牌同时承担“凑幸运数”和“输出/格挡/抽牌”的竞争用途。先用原型验证这种取舍是否好玩，再决定是否扩展卡牌种类。现有测试证明规则和流程可执行，不代表长期平衡和重复游玩深度已经验证。

## 2026-11-06：底部手牌与中央出牌区

手牌改为底部横向叠放，露出每张牌左侧数字，悬停轻微抬起。点击手牌或拖到中央出牌区，会将牌放入待出区域；点击中央的牌或拖回底部，可收回手牌。中央的牌仅是待确认选择，点击破防、攻击、换牌或弃牌按钮后才执行对应规则。无效落点回到原位置，不改变选择；补牌和结算阶段禁用出牌操作。

纯加法、攻击附效和牌库规则保持原样。界面调整与交互验收见 `Docs/Validation/TableCards`。
