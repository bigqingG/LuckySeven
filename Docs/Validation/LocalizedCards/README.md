# 中文、语言切换与扑克牌外观验收

日期：2026-11-07。

## 完成范围

- 默认简体中文。菜单、规则、生命/护甲、回合、抽换牌、卡牌能力、战斗反馈、结算等 63 项文案均有中英文条目。
- 右上角语言按钮使用 Unity Localization 切换，并保存选择；网页刷新后继续使用选中的语言。Web 加载页、页面标题和无障碍名称同步。
- 两个 locale 的 UIFont Asset Table 条目共用完整双语 Noto Sans SC 字库，无 TMP fallback 链。这样在异步切换的中间帧也能显示两种文字，避免暂时出现方框。
- 卡牌改为矢量圆角纸面、红黑花色、按数字排列的点数和倒置角标，保留中文/英文能力文字。
- 悬停牌面上移、放大、置于其他手牌上方。固定底部点击条使相邻牌仍可选；抬起的牌面自身也可点击。无法出牌的补牌/选择幸运数字阶段仍可悬停阅读。
